# Roadmap de habilidades

## Prioridad alta
- Power BI: Power Query, modelo estrella, DAX, visualización y seguridad.
- Excel avanzado: tablas dinámicas, Power Query, fórmulas de análisis y macros básicas.
- SQL: consultas, joins, agregaciones, CTEs y modelado.
- Power Apps + Power Automate: formularios, conectores, flujos y notificaciones.
- Inglés técnico: avanzar a B2.

## Prioridad media
- SharePoint y Dataverse.
- SAP: entender estructura, órdenes, materiales, inventario y exportación de datos.
- Lean/Kaizen/5S y KPIs industriales.
- ITIL y herramientas de mesa de ayuda como ServiceNow.
- Linux, Docker y automatización de despliegues.

## Después
- Azure Fundamentals / Azure DevOps.
- CI/CD para soluciones Power Platform.
- Gobierno y seguridad de Power Platform.
- Copilot Studio y agentes para automatización interna.
