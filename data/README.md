# Datos de demostración

Los datos del proyecto son sintéticos y representan un entorno industrial ficticio.

Para generarlos localmente:

```bash
python src/generate_demo_data.py
python src/etl.py
```

Se crean archivos CSV para producción, paros, mantenimiento, logística, calidad, inventario y energía. No contienen información de ninguna empresa real.
